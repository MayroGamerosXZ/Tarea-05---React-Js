1. Introducción al Proyecto

El sistema Command Center es una plataforma de gestión integral para talleres mecánicos de alto rendimiento. Su filosofía de diseño (UI/UX) se aleja del software corporativo tradicional para adoptar una estética de "Centro de Operaciones de Seguridad", utilizando fondos oscuros esmerilados (Frosted Glass), tipografías ágiles y acentos en naranja técnico para guiar la atención del operador.

El objetivo de la aplicación es digitalizar el flujo de trabajo: desde que un cliente deja su vehículo, pasando por la reparación y el consumo de refacciones, hasta la liquidación económica y el despacho final de la unidad.

2. Stack Tecnológico

Re

React.js (v19)

Biblioteca principal para construir la interfaz de usuario mediante componentes controlados y gestión de estado (Hooks).

Vi

Vite

Herramienta de empaquetado ultra-rápida (Bundler) que reemplaza a Webpack, ofreciendo Hot Module Replacement (HMR) instantáneo.

Tw

Tailwind CSS (v4)

Framework CSS de utilidades que permite estilizar componentes directamente en el marcado, soportando variables CSS modernas.

Lu

Lucide React

Librería de iconografía vectorial limpia y consistente que se adapta a la paleta de colores de Tailwind.

3. Arquitectura y Manejo del Estado

La arquitectura de la aplicación es del tipo Single Page Application (SPA). En lugar de recargar el navegador, un controlador maestro en App.jsx gestiona qué "Vista" se renderiza en el Main Content Area.

El estado se maneja a nivel global en el componente padre utilizando useState. Esto permite que si un repuesto se consume en el módulo de Órdenes, el módulo de Inventario y el de Notificaciones se enteren inmediatamente. La función clave para mantener esta sincronía es:

// Centralización de Lógica de Inventario
const handleStockMovement = (id, delta, actionName) => {
  setInventory(prev => prev.map(i => {
    if (i.id === id) {
      const newStock = Math.max(0, i.stock + delta);
      // Disparador automático de alertas si cruza el umbral mínimo
      if (newStock <= i.minStock && i.stock > i.minStock) {
        addNotification(`¡Alerta! Producto bajo en stock: ${i.name}`, 'warning');
      }
      return { ...i, stock: newStock };
    }
    return i;
  }));
};

4. Módulos del Sistema

Dashboard General

Funge como el panel de telemetría principal. Calcula matemáticamente los arreglos de datos del sistema para arrojar en tiempo real la cantidad de unidades en el taller, vehículos reparándose y vehículos facturados. Incluye una gráfica de barras simulada y un historial de actividad del sistema.

Gestión de Vehículos

Responsable del alta (Registro) de las unidades que llegan al negocio.

  • Apertura de un Modal desenfocado (backdrop-blur).
  • Captura de Placa, Modelo y Dueño.
  • Asignación automática del estado inicial Planificado y generación de ID (Ej. ORD-004).

Órdenes de Trabajo y Cobro Dinámico

Es el núcleo comercial de la aplicación. Permite avanzar un vehículo por el pipeline productivo (Planificado → En Reparación → Listo).

Cuando un auto está Listo, se habilita la ventana de Liquidación. Esta ventana posee las siguientes características técnicas:

  • Inyección de Dependencias: Lee el inventario global y renderiza solo piezas con stock > 0.
  • Cálculo Reactivo: Al agregar repuestos o editar mano de obra, recalcula el Subtotal, IVA (16%) y Total en tiempo real.
  • Mutación de Estado Dual: Al confirmar el pago, descuenta las piezas físicas del almacén y marca el vehículo permanentemente como "Despachado (Pagado)".

Control de Inventario

Administra el Catálogo de Repuestos. Soporta las siguientes operaciones:

  • Alta de Refacciones: Modal para registrar nuevos SKU, definiendo precio y stock mínimo de seguridad.
  • Eventos de Entrada/Salida: Botones explícitos para sumar inventario (Compras) o restar (Mermas).
  • Alertas visuales: Si el stock baja del límite seguro (minStock), renderiza una pastilla roja en la tabla y notifica a la campana superior.

5. Guía de Ejecución Local

Para levantar este proyecto en un entorno local (Windows/Mac/Linux), es necesario contar con Node.js instalado.

# 1. Clona el repositorio oficial de GitHub

git clone https://github.com/MayroGamerosXZ/Tarea-05---React-Js.git

# 2. Entra a la carpeta del proyecto

cd Tarea-05---React-Js

# 3. Instala las dependencias (React, Vite, Tailwind, Lucide)

npm install

# 4. Inicia el servidor ultra-rápido de desarrollo

npm run dev

La consola imprimirá una dirección local (usualmente http://localhost:5173). Ábrela en Google Chrome o Edge para utilizar el sistema.
